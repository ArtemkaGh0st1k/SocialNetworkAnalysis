**Лабораторная работа № 2**

В папке `lab2` содержатся следующие файлы и директории:

1. Модуль `clean_text.py` с функцией `load_and_clean_posts`, предназначенной для загрузки постов, собранных в первой лабораторной работе, и их очистки от эмодзи, ссылок, лишних пробелов и дубликатов.

2. Модуль `word_frequency.py`, предназначенный для лемматизации текстов, удаления стоп-слов и построения частотного словаря.

3. Модуль `k_selection.py`, предназначенный для проведения опыта при разных значениях `k` и выбора числа кластеров.

4. Модуль `text_clustering.py`, предназначенный для `TF-IDF` векторизации текстов, их кластеризации алгоритмами `KMeans`, `MiniBatchKMeans` и `AgglomerativeClustering` и визуализации результатов через `PCA`.

5. Модуль `pipeline.py`, запускающий все этапы по порядку через функцию `run_lab2_pipeline`.

6. Директория `resources` с описанием задания `LR2.docx`.

7. Директория `results`, содержащая результаты работы:

   * `word_frequency.csv` — частотный словарь;
   * `k_selection_metrics.csv` и `k_selection.png` — метрики и графики опыта при разных `k`;
   * `cluster_assignments.csv` — распределение постов по кластерам;
   * `cluster_sizes.csv` — количество постов в каждом кластере;
   * `cluster_top_terms.csv` — самые весомые слова кластеров;
   * `clusters_visualization.png` — визуализация кластеров;
   * `LR2_report.pdf` — отчёт по лабораторной работе.

6. Директория `results`, содержащая результаты работы. В репозитории хранится только файл `LR3_report.pdf` с подробным разбором работы. Остальные результаты содержат `id` реальных пользователей, поэтому хранятся локально:
