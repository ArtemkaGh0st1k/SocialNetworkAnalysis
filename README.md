**Лабораторная работа № 1**

В папке `lab1` содержатся следующие файлы и директории:

1. Модуль `collect_post_from_vk.py`, содержащий основной класс `VKParser`, предназначенный для парсинга данных сообщества Самарского университета во «ВКонтакте» (https://vk.ru/samara_university) за период с `01.08.2026` по `31.08.2026`.

   Парсер собирает следующие данные:

   * дату публикации;
   * текст публикации;
   * количество лайков;
   * количество комментариев;
   * количество репостов;
   * другие доступные поля публикации.

2. Скрытый файл `.env`, предназначенный для хранения `API_TOKEN`.

3. Директория `results`, содержащая результаты работы парсера в форматах `JSON` и `CSV`.

4. Файл `lab1/README.md` с подробным описанием работы первой лабораторной работы.

**Лабораторная работа № 3**

В папке `lab3` содержатся следующие файлы и директории:

1. Модуль `collect_friends.py`, содержащий класс `VKFriendsCollector`, предназначенный для сбора списка друзей пользователя VK и списков друзей каждого из его друзей.

2. Модуль `build_graph.py`, содержащий класс `FriendsGraphBuilder`, предназначенный для построения графа друзей и расчёта его метрик.

3. Модуль `visualize_graph.py`, содержащий класс `FriendsGraphVisualizer`, предназначенный для выделения сообществ и визуализации графа.

4. Модуль `pipeline.py`, запускающий все этапы по порядку через функцию `run_lab3_pipeline`.

5. Директория `resources` с описанием задания `LR3.docx`.

6. Директория `results`, содержащая результаты работы. В репозитории хранится только файл `LR3_report.pdf` с подробным разбором работы. Остальные результаты содержат `id` реальных пользователей, поэтому хранятся локально:

   * `my_acc` — результаты для моего аккаунта;
   * `another` — результаты для второго профиля, используемого для сравнения.

7. Файл `lab3/README.md` с подробным описанием работы третьей лабораторной работы.
